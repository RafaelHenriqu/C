## ⚠️ Observações técnicas (importante)

Este projeto foi feito em fase inicial de aprendizado, então alguns pontos não seguem boas práticas atuais de C:

* Uso de `char` para strings pequenas:

  * Em C, `char` representa apenas **um único caractere**
  * Strings completas devem ser tratadas como arrays de `char`

* Comparação de strings:

  * Comparações como `Type == "if"` **não funcionam corretamente em C**
  * O correto seria usar funções como `strcmp()`

* Funções sem `return`:

  * Algumas funções retornam `int`, mas não possuem `return`
  * Isso ocorreu porque o foco era apenas testar lógica e não estrutura completa de produção

* `main` como `void`:

  * Foi usado apenas como simplificação na época de estudo
